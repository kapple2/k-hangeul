# 한글 DOS 사용 설명서

K-HANGEUL v1.2b

K-HANGEUL을 올리면 DOS 3.3이 한글로 말하고, 한글 명령과 한글 파일 이름을 알아듣습니다. 이 문서는 그것을 쓰는 방법만 적었습니다. 만든 과정과 시험은 [DOS_KOREAN_REPORT.md](DOS_KOREAN_REPORT.md)에 있습니다. K-HANGEUL 전체 사용법은 [MANUAL.md](MANUAL.md)입니다.

## 1. 무엇이 달라지나

| | |
|---|---|
| **오류 메시지** | `FILE NOT FOUND` 대신 `파일을 찾을 수 없음` |
| **`CATALOG` 머리글** | `DISK VOLUME 254` 대신 `볼륨 254` |
| **명령 이름** | `CATALOG` 대신 `목록`, `SAVE` 대신 `저장` 같은 한글 이름 (영어 이름도 그대로 됩니다) |
| **파일 이름** | 한글로 시작하는 이름을 쓸 수 있고 `CATALOG`에 한글로 나옵니다 |

K-HANGEUL을 올리지 않은 DOS는 전과 같습니다. 영어로 쓰던 프로그램과 디스크는 아무 영향이 없습니다.

## 2. 어떤 카드에서 되나

| 카드 | 한글 DOS | `포맷`(`INIT`) |
|---|---|---|
| 16KB 랭귀지 카드 | 됩니다 | 디스크를 포맷합니다 |
| 128K Saturn 카드 | 됩니다 | 포맷하지 않고 `HAN`처럼 드라이버를 다시 시작합니다 |

Saturn 카드에서 디스크를 포맷하려면 16KB 카드에서 하거나 K-HANGEUL 없이 부팅해서 하세요. 128K가 아닌 Saturn 카드에서는 DOS가 영어 그대로입니다. DOS 3.3(48K용)이 필요합니다.

## 3. 한글 오류 메시지

| DOS | 한글 | DOS | 한글 |
|---|---|---|---|
| `LANGUAGE NOT AVAILABLE` | 언어 없음 | `FILE LOCKED` | 파일 잠김 |
| `RANGE ERROR` | 범위 오류 | `SYNTAX ERROR` | 문법 오류 |
| `WRITE PROTECTED` | 쓰기 금지됨 | `NO BUFFERS AVAILABLE` | 버퍼 부족 |
| `END OF DATA` | 자료 끝 | `FILE TYPE MISMATCH` | 파일 종류 다름 |
| `FILE NOT FOUND` | 파일을 찾을 수 없음 | `PROGRAM TOO LARGE` | 프로그램이 너무 큼 |
| `VOLUME MISMATCH` | 볼륨 번호 다름 | `NOT DIRECT COMMAND` | 직접 명령 아님 |
| `I/O ERROR` | 입출력 오류 | `DISK VOLUME` (CATALOG 머리글) | 볼륨 |
| `DISK FULL` | 디스크 가득 참 | | |

- `ONERR GOTO`가 받는 오류 번호는 그대로입니다. 오류 메시지의 글을 읽는 프로그램은 한글을 받습니다.
- 애플소프트의 메시지(`?SYNTAX ERROR` 등)는 애플 II 롬에 있어서 영어 그대로입니다. 위 표는 DOS의 메시지입니다.

## 4. 한글 명령 이름

`PR#`, `IN#`, `FP`를 뺀 모든 DOS 명령에 한글 이름이 있습니다.

| 한글 | DOS | 한글 | DOS | 한글 | DOS |
|---|---|---|---|---|---|
| 포맷 | `INIT` | 닫기 | `CLOSE` | 감시 | `MON` |
| 불러오기 | `LOAD` | 읽기 | `READ` | 감시끝 | `NOMON` |
| 저장 | `SAVE` | 일괄 | `EXEC` | 최대파일 | `MAXFILES` |
| 실행 | `RUN` | 쓰기 | `WRITE` | 한글 | `HAN` |
| 연결 | `CHAIN` | 자리 | `POSITION` | 이진저장 | `BSAVE` |
| 지우기 | `DELETE` | 열기 | `OPEN` | 이진불러오기 | `BLOAD` |
| 잠금 | `LOCK` | 이어쓰기 | `APPEND` | 이진가동 | `BRUN` |
| 풀기 | `UNLOCK` | 이름바꿈 | `RENAME` | 검사 | `VERIFY` |
| 목록 | `CATALOG` | | | | |

### 치는 법

1. Ctrl-K를 누르고 명령 이름을 칩니다. 그다음 공백을 칩니다.
2. 파일 이름을 칩니다.
   - **영어** 파일 이름이나 옵션이면 먼저 **Ctrl-A**를 누릅니다.
   - **한글** 파일 이름이면 그대로 한글을 이어 칩니다.

```
목록                          (Ctrl-K 목록)
저장 한글                     (파일 이름이 한글)
저장 [Ctrl-A] T1              (파일 이름이 영어)
이진저장 [Ctrl-A] B1,A$300,L4
불러오기 한글
최대파일 2
```

숫자는 바로 이어 쳐도 됩니다(`최대파일 2`). 다만 `MAXFILES`는 쓰지 마세요(8절).

- 명령 이름은 줄의 **첫 낱말**이어야 합니다.
- 영어 이름 `LOAD`, `SAVE`, `CATALOG` 등도 전처럼 됩니다. 한글 이름을 쓰지 않아도 됩니다.

### BASIC 프로그램 안에서

`CHR$(4)` 뒤에 DOS 명령을 `PRINT`하는 줄에서도 같게 씁니다.

```
10 D$ = CHR$(4)
20 PRINT D$ "열기 TX"
30 PRINT D$ "쓰기 TX"
40 PRINT "HELLO"
50 PRINT D$ "닫기"
```

- 명령 이름 앞에 Ctrl-K를 넣습니다. 닫는 따옴표 앞에는 Ctrl-A가 필요 없습니다.
- 파일 이름이 영어이면 이름 앞에 Ctrl-A를 넣습니다.
- 직접 명령이 아닌 `열기`, `쓰기`, `읽기`, `이어쓰기`를 줄 번호 없이 치면 `직접 명령 아님`이 나옵니다. 원래 DOS와 같은 동작입니다. 프로그램 줄로 넣으세요.

## 5. 한글 파일 이름

`SAVE` 뒤에 한글 이름을 쓸 수 있습니다.

```
SAVE [Ctrl-K] 한글 [Ctrl-A]
```

- `CATALOG`(`목록`)에 한글로 나옵니다.
- 이름은 **대략 7~9음절**까지 들어갑니다(DOS의 이름 한도가 30바이트이고 한글 한 글자가 3~4바이트를 씁니다). 영어를 섞으면 더 적습니다.
- 한글 이름 뒤에 쉼표와 옵션이 와도 됩니다.

```
BSAVE B한,A$300,L4
RENAME 한글,글한
목록,D1
```

- 같은 이름은 같은 방식으로 쳐야 일치합니다.

### 남에게 주는 디스크는 영어 이름으로

디스크에는 표준 한글 코드가 아니라 자판 코드가 저장됩니다. K-HANGEUL이 없는 Apple II나 다른 디스크 도구에서는 한글 파일 이름이 잡음처럼 보입니다. 파일은 그래도 읽히지만, 남에게 주거나 다른 기계에서 쓸 디스크는 **영어 이름**을 쓰세요.

## 6. 포맷(`INIT`)

**16KB 카드:** 보통 DOS 3.3처럼 디스크를 포맷하고 메모리의 프로그램을 거기에 저장합니다.

```
10 PRINT "HI"
포맷 HELLO
```

- 새 디스크는 **원래 DOS 3.3**을 받습니다. K-HANGEUL이 없는 컴퓨터에서도 부팅합니다. 그 디스크에서 한글을 쓰려면 MANUAL.md 9절처럼 파일을 복사하세요.
- 쓰기 금지된 디스크이거나 오류가 나면 `입출력 오류`를 찍고 디스크는 그대로입니다. 이어서 한글 명령을 계속 쓸 수 있습니다.

**Saturn 카드:** 포맷하지 않고 드라이버를 다시 시작합니다(2절).

## 7. 파일 목록

`목록`(`CATALOG`)은 한 쪽(화면 16줄)마다 멈춥니다. 머리글이 `볼륨 254`로 나옵니다.

- 멈춘 곳에서 아무 키나 누르면 다음 쪽이 나옵니다.
- **Ctrl-C** 를 누르면 목록을 그만 보고 `]` 로 돌아갑니다. (원래 DOS 3.3 에서는 Ctrl-C 도 그냥 다음 쪽 키였습니다.) 영어 `CATALOG` 도 같습니다.
- **Ctrl-Reset** 으로도 빠져나올 수 있습니다. 한글 드라이버가 저절로 다시 시작하므로 `HAN` 을 칠 필요가 없습니다(16K 카드는 시작 화면이 다시 나옵니다). 실행 중이던 BASIC 프로그램은 그대로 남습니다.

## 8. 알아 두어야 할 것

- **`MAXFILES`(`최대파일`)는 쓰지 마세요.** 드라이버가 쓰는 메모리 보호가 풀립니다.
- **한글 명령 이름 바로 뒤의 한글 파일 이름**은 한글 글자로 시작해야 한글로 받아들여집니다. 숫자나 기호로 시작하면 영어로 읽습니다. 그럴 때는 Ctrl-A를 누르고 영어 이름을 치세요.
- **명령이 아닌 한글 낱말**을 줄 처음에 치면 전처럼 `?SYNTAX ERROR`입니다. 아주 드물게(대략 2,600낱말에 하나) 명령 이름과 우연히 같게 읽히는 낱말이 있습니다.
- **`PR#0`**(드라이버 끔) 뒤에는 오류 메시지가 영어로 돌아오고 `CATALOG` 머리글은 알 수 없는 글자(`QHFFBA 254`)로 나옵니다. `HAN`을 쳐서 드라이버를 다시 켜세요.
- **한글 모드가 켜진 채 남을 때.** 따옴표 안에 한글을 넣은 줄을 Ctrl-A 없이 치면, 다음에 치는 `RUN` 같은 영어가 자모로 나옵니다. Ctrl-A로 끄고 치세요.
- **쉼표가 든 한글 글.** `PRINT "한, 글"`이나 `DATA 한,글`은 쉼표마다 2바이트 길어집니다(`LEN`에 셈). 보이는 모양과 출력은 같습니다.
- **K-BASIC을 올린 경우.** `실행`과 `읽기`는 K-BASIC의 낱말이기도 합니다. K-BASIC이 스스로 `RUN`과 `READ`로 바꾸니 결과는 같습니다. 그러나 K-BASIC은 한글 파일 이름 안의 자기 낱말도 바꾸므로, **파일 이름에 K-BASIC 낱말을 피하세요**(`읽기파일` 같은 이름은 `READ…`로 바뀝니다).
- **`INIT` 오류를 `ONERR GOTO`로 받는 프로그램**은 다음 DOS 오류 메시지나 다음 `INIT` 때까지 DOS가 영어로, 한글 이름 없이 남을 수 있습니다.
- **드라이버가 없는 컴퓨터**에서는 한글 명령이 든 프로그램이 `?SYNTAX ERROR`로 멈춥니다. DOS가 한글 명령을 아는 것은 K-HANGEUL을 올린 동안뿐입니다.
- **이 DOS 3.3과 다른 DOS**(고친 DOS 등)에서는 달라진 자리의 한글화를 건너뜁니다. 그 부분은 영어 그대로 남습니다.

## 9. 시험해 본 환경

MAME(Apple II+ 에뮬레이터)에서 16KB 카드와 128K Saturn 카드 모두 위 내용을 확인했습니다. **실제 기계, Apple IIe/IIc/IIgs, 128K가 아닌 Saturn 카드는 시험하지 못했습니다.**
