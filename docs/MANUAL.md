# K-HANGEUL (캐플한글) v1.0b 사용 설명서

> English version: [MANUAL_en.md](MANUAL_en.md)


## 1. 이것은 무엇인가

**K-HANGEUL**은 애플 II+ 의 고해상도(HGR) 화면에 **작지만 읽기 쉬운 12×12 한글**을 보여 주는 드라이버입니다. 한글2(Hangeul2)를 고쳐 만들었습니다. 주 용도는 **텍스트 BASIC 프로그램을 한글로 쓰는 것**입니다. 프로그램 목록(`LIST`)과 실행 화면에서 한글이 그대로 보입니다.

- 화면: 가로 46칸 × 세로 16줄. 영문·숫자는 한 칸, 한글 한 글자는 두 칸이라 한 줄에 한글 23자가 들어갑니다.
- 글자 크기: 한글 12×12, 영문 6×10 (12줄 칸의 아래쪽 10줄에 그려집니다. 영문 글꼴은 별도 파일 `FONT6X10`).
- BASIC 프로그램 공간: 약 21.5KB (`HIMEM`이 `$9400`). 시작 때 화면에 남은 바이트 수가 표시됩니다.


## 2. 필요한 것

- 애플 II+ (48K RAM) 와 **랭귀지 카드(16K)**. 드라이버가 카드 안에 들어갑니다.
- DOS 3.3 (48K용). 이 디스크의 DOS를 쓰거나, 아래 8절처럼 자기 디스크에 파일을 복사합니다.


## 3. 디스크에 있는 파일

`CATALOG`로 보면 33개입니다. 앞의 8개가 한글 드라이버와 기본 파일이고, 나머지는 예제입니다. 다른 파일(`ASCII`, `MASKS` 등 한글2의 옛 파일)은 필요 없어서 넣지 않았습니다.

| 파일 | 종류 | 설명 |
|---|---|---|
| `HELLO` | BASIC | 부팅 때 자동으로 실행됩니다. `FONT12`, `FONT6X10`을 읽어 오고 `K-HANGEUL`을 실행합니다. |
| `K-HANGEUL` | 바이너리 `$0F94` | 한글 드라이버 본체. 랭귀지 카드에 올라가 화면 출력과 키 입력을 맡습니다. |
| `FONT12` | 바이너리 `$6000` | 12×12 한글 글꼴. 부팅 때 읽어 메모리로 옮깁니다. 이 파일을 바꾸면 한글 글꼴이 바뀝니다. |
| `FONT6X10` | 바이너리 `$7200` | 6×10 영문 글꼴(글자 128개). 부팅 때 읽어 랭귀지 카드로 옮깁니다. 이 파일을 바꾸면 영문 글꼴이 바뀝니다. |
| `TYPE` | 바이너리 `$8E00` | 선택. 텍스트 파일을 한글로 찍는 BASIC 명령 `& TYPE`을 추가합니다. |
| `TYPEC` | 바이너리 `$8E00` | 선택. `]` 프롬프트에서 파일 이름을 물어보고 한글 텍스트 파일을 찍어 주는 프로그램. |
| `STYPE` | 바이너리 `$8A00` | 선택. `TYPE` 과 같지만 한 줄씩 위에서 아래로 한 픽셀 줄씩 부드럽게 나타나게 찍는 `& STYPE` 명령을 추가합니다. `TYPE` 과 함께 올릴 수 없습니다. |
| `STYPEC` | 바이너리 `$8A00` | 선택. `TYPEC` 의 부드러운 버전(파일 이름 뒤에 `,숫자` 로 기다리는 시간). |
| `SAMPLE1` | 텍스트 | `TYPE`, `TYPEC` 시험용 한글 텍스트 파일. |
| `DEMO` | BASIC | 한글이 들어 있는 짧은 BASIC 프로그램. `RUN DEMO` 또는 `LOAD DEMO` 후 `LIST`. |
| `MIXED` | BASIC | 짧은 섞어 쓴 글(`SAMPLE1`: 겹받침, 쌍자음, 영문, 숫자)을 **BASIC 만으로** 읽어서 찍는 프로그램. `RUN MIXED`. |
| `NALGAE1` … `NALGAE16` | 텍스트 | 긴 글: 이상의 「날개」 전체(약 57KB, 16쪽으로 나눔). |
| `STORY` | BASIC | `NALGAE1`…`16` 을 **BASIC 만으로** 읽어서 찍는 프로그램. `RUN STORY`. |
| `SAMPLEB` | 바이너리 `$8000` | 메모리에서 찍기 예제용 짧은 글. |
| `TYPEDEMO` | BASIC | `& TYPE` 예제: 파일(`SAMPLE1`)과 메모리(`SAMPLEB`)의 글을 찍습니다. `RUN TYPEDEMO`. |
| `STORYT` | BASIC | `& TYPE` 으로 「날개」를 16쪽 모두 찍는 3줄짜리 프로그램. `RUN STORYT`. |
| `STYPEDEMO` | BASIC | `& STYPE` 예제: 기다림 없이, 기다림 20으로, 메모리에서. `RUN STYPEDEMO`. |
| `STORYS` | BASIC | `& STYPE` 으로 「날개」를 부드럽게 찍는 프로그램. `RUN STORYS`. |


## 4. 시작하기

디스크를 1번 드라이브에 넣고 켭니다. 화면 위쪽에 `캐플한글 v1.0b 2026년 (한글2 수정버전)` 와 여유 메모리가 나온 뒤 `]` 프롬프트가 나오면 준비된 것입니다.

> `HELLO`가 드라이버를 실행할 때 메모리의 BASIC 프로그램은 지워집니다(`NEW`와 같음). 부팅한 뒤에 프로그램을 불러오세요.

`RUN DEMO`를 해 보세요.


## 5. 한글 입력

한글 모드로 들어가는 키는 **Ctrl-K**, 나오는 키는 **Ctrl-A** 입니다. Ctrl-K와 Ctrl-A 사이에서 **2벌식 자판**의 자모를 누르면 글자가 조합됩니다. 대문자 모드(애플 II+ 기본)에서 누르면 됩니다.

키 위의 글자가 누르는 키, 아래의 글자가 치는 자모입니다. 키 위치는 실제 자판과 같습니다. 같은 키에 Shift 를 누르면 된소리나 ㅒ ㅖ 가 됩니다(개조가 있을 때).

```
┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
│ Q  ││ W  ││ E  ││ R  ││ T  ││ Y  ││ U  ││ I  ││ O  ││ P  │
│ ㅂ ││ ㅈ ││ ㄷ ││ ㄱ ││ ㅅ ││ ㅛ ││ ㅕ ││ ㅑ ││ ㅐ ││ ㅔ │
└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘
  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
  │ A  ││ S  ││ D  ││ F  ││ G  ││ H  ││ J  ││ K  ││ L  │
  │ ㅁ ││ ㄴ ││ ㅇ ││ ㄹ ││ ㅎ ││ ㅗ ││ ㅓ ││ ㅏ ││ ㅣ │
  └────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘
    ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
    │ Z  ││ X  ││ C  ││ V  ││ B  ││ N  ││ M  │
    │ ㅋ ││ ㅌ ││ ㅊ ││ ㅍ ││ ㅠ ││ ㅜ ││ ㅡ │
    └────┘└────┘└────┘└────┘└────┘└────┘└────┘
```


- 된소리 ㄲ ㄸ ㅃ ㅆ ㅉ 는 `-` `=` `*` `<` `>` 키, ㅒ 는 `;`, ㅖ 는 `+` 키입니다. **Shift 키 개조가 없는 기계**(아래 참고)에서는 Ctrl 이 아니라, 애플 II+ 자판에서 그 기호를 치는 방법 그대로 누릅니다:
  (`Sh-` 는 Shift 를 누른 채 `-` 키를 치는 것입니다.)

  ```
  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
  │ -  ││Sh- ││Sh: ││Sh, ││Sh. ││ ;  ││Sh; │
  │ ㄲ ││ ㄸ ││ ㅃ ││ ㅆ ││ ㅉ ││ ㅒ ││ ㅖ │
  └────┘└────┘└────┘└────┘└────┘└────┘└────┘
  ```

  (애플 II+ 자판의 Shift 는 기호 키의 윗글자를 치는 데 쓰이며, 기계 안에서는 따로 구별되지 않습니다. 그래서 Shift 키 개조가 없어도 위 방법으로 모두 칠 수 있습니다.)

  **애플 IIe, IIc, IIgs 에서는** 자판이 다릅니다. Shift+`-` 는 `_`, Shift+`;` 는 `:` 이고, `*` 는 Shift+8 입니다. 드라이버가 이를 알고 한글 모드에서 `_` 를 `=`(ㄸ)로, `:` 를 `+`(ㅖ)로 바꾸므로 위 그림이 이 기계들에서도 그대로 됩니다. (그래서 이 기계들의 한글 모드에서는 `:` 키로 ₩ 를 칠 수 없습니다.) ㅃ 은 II+ 에서 Shift+`:` 이고 IIe 에서는 Shift+8(`*`)입니다.
- **Shift 키 개조가 있으면** 된소리와 ㅒ ㅖ 를 Shift 와 함께 누를 수 있습니다(2벌식 자판과 같습니다): Shift+R = ㄲ, Shift+E = ㄸ, Shift+Q = ㅃ, Shift+T = ㅆ, Shift+W = ㅉ, Shift+O = ㅒ, Shift+P = ㅖ. 개조가 없으면 위의 `-` `=` `*` `<` `>` `;` `+` 키를 씁니다(둘 다 됩니다). 한글 모드에서만 동작하고, 입력한 글은 그대로 저장되므로 기존 프로그램과 텍스트 파일은 바뀌지 않습니다.

  Shift 키 개조가 있을 때 Shift 와 함께 누르는 키:

  ```
  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
  │ R  ││ E  ││ Q  ││ T  ││ W  ││ O  ││ P  │
  │ ㄲ ││ ㄸ ││ ㅃ ││ ㅆ ││ ㅉ ││ ㅒ ││ ㅖ │
  └────┘└────┘└────┘└────┘└────┘└────┘└────┘
  ```
  - Shift 키 개조는 Shift 키를 게임 포트의 단추 2(`$C063`)에 연결하는 것입니다. 에뮬레이터 MAME(애플 II+ 기본값 "SW2 = Shift")에서 확인했습니다. 드라이버는 시작할 때 이 단추의 상태를 "Shift 안 누름"으로 기억하므로, **시작할 때(부팅할 때) Shift 키나 게임 단추 2를 누르고 있지 마세요.**
  - 게임 단추 2를 누르고 있으면 Shift 로 인식됩니다. 에뮬레이터 AppleWin 에서도 되지만 조이스틱 2 를 꺼 두어야 합니다.
  - **애플 IIe, IIc, IIgs 에서는 소프트웨어가 Shift 키를 읽을 수 없습니다**(IIe 와 인핸스드 IIe 는 그것을 이어 주는 기판 자리가 끊겨 있습니다). 그래서 드라이버는 시작할 때 이런 기계를 알아보고 **Open-Apple 키**를 대신 씁니다. Open-Apple 을 누른 채 R E Q T W O P 를 누르면 ㄲ ㄸ ㅃ ㅆ ㅉ ㅒ ㅖ 가 됩니다. AppleWin 에서는 Open-Apple 이 왼쪽 Alt 키이고(Solid-Apple 은 오른쪽 Alt), 이 기계들에서 Shift 키는 이 용도로 쓰이지 않습니다. `-` `=` `*` `<` `>` `;` `+` 키는 어디서나 됩니다.
- 겹모음은 모음 키를 이어서 누릅니다. 예: ㅘ = H K, ㅝ = N J, ㅢ = M L. 겹받침도 이어서 누릅니다. 예: ㄳ = R T, ㄺ = F R.
- 예: `한글` 은 **Ctrl-K** `G K S R M F` **Ctrl-A**. `까따빠` 는 **Ctrl-K** `- K = K * K` **Ctrl-A**.
- 방향키 ←(백스페이스)로 지울 수 있습니다.

**편집 키** (한글2에서 이어받은 키 가운데 이 드라이버에서 직접 확인한 것입니다)

Ctrl 과 함께 누르는 키(키 위의 글자)와 그 기능(아래 글자)입니다. 표시가 없는 키는 아직 쓰지 않습니다.

```
┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
│ Q  ││ W  ││ E  ││ R  ││ T  ││ Y  ││ U  ││ I  ││ O  ││ P  │
│    ││    ││DEL>││INS ││    ││HOME││ -> ││INV ││NRM ││    │
└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘
  ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
  │ A  ││ S  ││ D  ││ F  ││ G  ││ H  ││ J  ││ K  ││ L  │
  │ENG ││    ││    ││    ││    ││ <- ││    ││HAN ││CLR │
  └────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘└────┘
    ┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐┌────┐
    │ Z  ││ X  ││ C  ││ V  ││ B  ││ N  ││ M  │
    │    ││DEL ││CAN ││ UP ││BOL ││EOL ││    │
    └────┘└────┘└────┘└────┘└────┘└────┘└────┘
```

약어: HOME 홈 위치 · DEL 글자 하나 지우기 · DEL> 커서부터 줄 끝까지 지우기 · INS 끼워 넣기 켜기/끄기 · INV/NRM 반전/보통 · <- -> 한 칸 왼쪽/오른쪽 · BOL/EOL 줄 맨 앞/끝 · CAN 친 줄을 버리고 다음 줄 · UP 화면을 한 줄 아래로 밀기 · CLR 화면 지우기 · ENG/HAN 영문/한글 모드

이 드라이버에서 아직 확인하지 않은 키는 Ctrl-F, Ctrl-P, Ctrl-J, Ctrl-G, Ctrl-T, Ctrl-@, Ctrl-] 입니다. Ctrl-Z 는 편집 중에는 아무 일도 하지 않습니다. Ctrl-S 는 입력을 멈추지 않습니다(멈춤은 `TYPE`, `STYPE` 에서만 됩니다).


## 6. BASIC 프로그램에 한글 쓰기

문자열 안에서 Ctrl-K … Ctrl-A 로 한글을 입력합니다.

```
10 PRINT "안녕하세요"      <- 실제로는 PRINT " [Ctrl-K] D K S S U D G K T P D Y [Ctrl-A] "
RUN
```

프로그램에는 한글이 Ctrl-K, 영문자, Ctrl-A 의 순서로 들어가고, `LIST` 하면 화면에 한글로 보입니다. `SAVE`, `LOAD`, `RUN` 은 보통 BASIC 파일과 같이 동작합니다. 한글을 쓴 프로그램은 이 드라이버가 올라간 상태에서만 제대로 보입니다. 드라이버가 없으면 `GKSRMF` 같은 영문자로 보입니다.

`DEMO` 프로그램을 `LIST` 해서 어떻게 보이는지 확인해 보세요.

**글자 모양: 반전, 밑줄, 겹쳐 쓰기**

한글과 영문 모두 됩니다. 프로그램 안에서도, `]` 프롬프트에서도 쓸 수 있습니다.

- **반전**: `INVERSE` 다음에 찍는 글자는 흰 바탕에 검은 글자로 나옵니다. `NORMAL` 로 보통 글자로 돌아옵니다. `FLASH` 도 반전과 같게 보입니다(깜박이지는 않습니다).

  ```
  PRINT "A ";: INVERSE: PRINT "INV";: NORMAL: PRINT " B"
  ```

- **밑줄**: `CALL 38257;UL ON` 을 하면 그 뒤에 찍는 글자 밑에 선이 그어지고, `CALL 38257;UL OFF` 로 끝납니다. 글자 칸의 맨 아래 줄을 선으로 채우므로 글자 사이가 이어진 선으로 보입니다.

  ```
  CALL 38257;UL ON: PRINT "UNDER": CALL 38257;UL OFF
  ```

- **겹쳐 쓰기**: 보통은 글자를 찍기 전에 그 칸을 지우고 찍습니다. `CALL 38257;OR ON` 을 하면 칸을 지우지 않고 이미 있는 모양 위에 덧그립니다. 예를 들어 `O` 를 찍고 `HTAB` 로 같은 자리로 돌아와 `/` 를 찍으면 `Ø` 가 됩니다. `CALL 38257;OR OFF` 로 보통 방식으로 돌아옵니다.

  ```
  CALL 38257;OR ON: PRINT "O";: HTAB 1: PRINT "/": CALL 38257;OR OFF
  ```

`CALL` 뒤의 수 **38257** 은 이 드라이버가 명령을 받는 주소입니다. 옛 한글2 설명서에는 `CALL 2000;` 이라고 쓰여 있지만, 이 드라이버는 그 자리(글자 화면 안)를 쓰지 않도록 옮겼으므로 `CALL 2000;` 을 하면 모니터로 빠집니다. 반드시 38257 을 쓰세요.


## 7. 한글 텍스트 파일 찍기: `TYPE`, `TYPEC`

한글 텍스트 파일은 "N바이트" 방식입니다. 한글은 Ctrl-K, 2벌식 영문자, Ctrl-A 로, 영문과 숫자는 그대로 들어 있습니다. DOS 텍스트 파일(T)이어야 하고, 이 디스크의 `SAMPLE1` 이 예입니다.

**`TYPEC` (명령 줄에서)**

```
]BRUN TYPEC

FILE NAME
]SAMPLE1
```

파일 이름을 입력하면 찍어 줍니다. 계속 다른 파일 이름을 물어보고, 빈 줄(Return)을 치면 끝납니다. 소문자도 됩니다. 없는 파일이면 `FILE NOT FOUND` 입니다.

**`& TYPE` (BASIC 프로그램에서, 또는 `]` 프롬프트에서)**

```
]BRUN TYPE
]& TYPE,"SAMPLE1"
```

한 번 `BRUN TYPE` 으로 올려 두면 `& TYPE,"파일이름"` 을 프로그램 안에서도 쓸 수 있습니다. 파일을 열고 닫는 `OPEN`/`READ`/`CLOSE` 는 필요 없습니다. 메모리에 올린 텍스트를 찍을 때는 `& TYPE,"$8000"` 또는 `& TYPE,32768` 처럼 주소를 씁니다(텍스트 끝은 `$00`).

두 프로그램 모두 `HIMEM` 근처 메모리를 쓰므로, `BRUN TYPE` 은 프로그램 시작에서 하는 것이 안전합니다.

**`& TYPE` 을 쓰는 BASIC 프로그램 전체 예** (이 디스크에서 그대로 실행해 확인했습니다):

```
10 REM &TYPE DEMO
20 PRINT CHR$(4);"BRUN TYPE"
30 ONERR GOTO 100
40 HOME
50 & TYPE,"SAMPLE1"
60 PRINT "-----"
70 INPUT "FILE NAME? ";F$
80 & TYPE,F$
90 END
100 IF PEEK(222) = 6 THEN PRINT "FILE NOT FOUND": END
110 PRINT "ERROR ";PEEK(222): END
```

- 20줄: `TYPE` 을 올립니다. 프로그램 시작에서 한 번만 합니다.
- 30줄: 없는 파일이나 디스크 오류가 나면 100줄로 갑니다 (`ONERR GOTO`).
- 50줄: 파일 이름을 문자열로 줍니다. 파일을 읽고 화면에 찍는 것까지 `& TYPE` 이 합니다.
- 70줄: 파일 이름을 물어봅니다. 80줄에서 `& TYPE,F$` 처럼 문자열 변수로 줄 수 있습니다. 없는 이름을 치면 100줄로 갑니다.
- 100줄: `PEEK(222)` 는 오류 번호입니다. 6 은 `FILE NOT FOUND` 입니다.


**긴 글과 섞어 쓴 글 (예제)**

- `RUN MIXED` : `SAMPLE1` 을 읽어서 찍습니다. 한글(겹받침 값 밝 앉 읽 훑 짧, 쌍자음), 영문, 숫자가 한 화면에 섞여 있습니다.
- `RUN STORY` : 「날개」 16개 파일을 차례로 읽어 찍습니다. 글이 쉬지 않고 위로 올라가며 끝까지 한참 걸립니다. 한 파일만 보고 싶으면 `BRUN TYPEC` 후 파일 이름(예: `NALGAE1`)을 치세요.
- `RUN STORYT` : 같은 글을 `& TYPE` 으로 찍습니다. 프로그램이 세 줄(`BRUN TYPE`, `FOR`, `& TYPE,"NALGAE"+STR$(N)`)이라 짧고 빠릅니다.

`MIXED` 와 `STORY` 는 `POKE` 나 기계어 없이 `OPEN`, `READ`, `GET A$`, `PRINT A$;` 만 쓰는 BASIC 입니다(파일 끝을 알려 주는 `ONERR GOTO` 와, 그 오류를 지우는 `POKE 216,0` 한 줄만 예외). `LIST` 로 읽어 보면 한글 텍스트 파일을 BASIC 에서 직접 읽는 방법을 알 수 있습니다:

```
10 REM PRINT SAMPLE, KEYSTROKES PLUS ENGLISH
20 D$ = CHR$ (4)
30 N = 1
40 F$ = "SAMPLE" + STR$ (N)
50 PRINT D$;"OPEN ";F$
60 PRINT D$;"READ ";F$
70 ONERR  GOTO 100
80 GET A$: PRINT A$;: GOTO 80
100 POKE 216,0: PRINT D$;"CLOSE":N = N + 1: IF N <= 1 THEN 40
110 END
```

**부드럽게 찍기: `STYPE`, `STYPEC`**

`TYPE` 과 같은 일을 하되, 글자를 하나씩 찍는 대신 **한 줄을 먼저 보이지 않는 곳에 그린 다음 위에서 아래로 한 픽셀 줄씩 보여 줍니다**. 줄이 부드럽게 펼쳐지는 것처럼 보입니다. 화면이 위로 올라가는 것은 평소와 같습니다.

```
]BRUN STYPE
]& STYPE,"NALGAE1"          <- 기다림 없이
]& STYPE,"NALGAE1",5        <- 한 픽셀 줄마다 약 5 밀리초 기다림
]& STYPE,"$8000",5          <- 메모리의 글을 (주소는 16진수나 10진수)
```

- 세 번째 값(0~255, 숫자 식이면 됩니다)이 **기다리는 시간**입니다. 없으면 0 이라 기다리지 않고 한 줄이 거의 한꺼번에 나타나므로, 효과를 보려면 `5` 이상을 주세요. 한 줄은 12 픽셀 줄이라 기다림 5 이면 한 줄에 약 60 밀리초가 걸립니다.
- 46칸보다 긴 줄은 46칸씩 나누어, 줄마다 따로 부드럽게 나타납니다.
- `STYPE` 은 `TYPE` 과 같은 방식으로 파일을 읽습니다(그림 그리는 속도도 같습니다). 줄마다 약 8 밀리초가 더 걸리고(「날개」1쪽에서 0.7초, MAME 로 잰 값), 기다림은 그 위에 더해집니다.
- **멈추기**: 찍는 도중 **Ctrl-C** 를 누르면 `TYPE`, `STYPE`, `TYPEC`, `STYPEC` 모두 멈춥니다(`TYPEC`, `STYPEC` 는 `FILE NAME` 으로 돌아갑니다). Ctrl-S 는 잠시 멈춤(아무 키나 누르면 계속), Ctrl-Reset 은 강제로 빠져나옴(이후 `HAN`). `STORYT` 같은 BASIC 반복문에서는 Ctrl-C 가 지금 찍는 파일만 멈추고 다음 파일로 넘어가므로, 프로그램 전체를 멈추려면 Ctrl-Reset 을 쓰세요.
- `TYPE` 과 `STYPE` 은 **함께 올릴 수 없습니다**. `STYPE` 은 BASIC 메모리를 약 3KB 씁니다(`TYPE` 은 1.5KB). 프로그램 맨 앞에서 `BRUN STYPE` 을 하세요.
- `STYPEC` 는 `TYPEC` 의 부드러운 버전입니다: `BRUN STYPEC`, `FILE NAME` 에 `NALGAE1,5` 처럼 이름 뒤에 쉼표와 기다림을 씁니다. BASIC 메모리 위쪽 2.5KB 를 덮어쓰므로 `]` 프롬프트에서(프로그램이 없을 때) 쓰세요.
- 디스크의 `RUN STYPEDEMO` 와 `RUN STORYS` 가 예제입니다.


## 8. 자기 DOS 3.3 디스크에서 쓰기

이 디스크가 아니어도 됩니다. 다음 네 파일을 자기 디스크로 복사합니다(AppleCommander, CiderPress 등).

| 파일 | 종류, 주소 |
|---|---|
| `FONT12` | 바이너리, `A$6000` |
| `FONT6X10` | 바이너리, `A$7200` |
| `K-HANGEUL` | 바이너리, `A$0F94` |
| `HELLO` (또는 부팅 프로그램의 맨 앞 세 줄) | `10 PRINT CHR$(4)"BLOAD FONT12,A$6000"` / `20 PRINT CHR$(4)"BLOAD FONT6X10,A$7200"` / `30 PRINT CHR$(4)"BRUN K-HANGEUL"` |

DOS 3.3(48K용)이 필요합니다. `BRUN K-HANGEUL` 을 하면 메모리의 BASIC 프로그램이 지워지므로, 이 세 줄을 먼저 실행한 뒤 자기 프로그램을 `RUN` 하세요.


## 9. 알아 두면 좋은 것

- **`HAN` 명령**: `PR#0`, `IN#0` 로 한글 드라이버가 꺼졌을 때 `HAN` 을 입력하면 다시 켜지고 화면을 지웁니다. Ctrl-Reset 으로 드라이버가 꺼졌을 때도 같습니다 (에뮬레이터 MAME 의 Ctrl-Reset 으로 확인했습니다. 실제 기계에서는 아직 해 보지 못했습니다).
- **`HOME`** 은 한글 화면을 지웁니다. `CATALOG` 는 화면 16줄에 맞춰 한 쪽씩 멈춥니다.
- **`HGR2` 는 쓰지 마세요.** 애플소프트의 `HGR`, `HGR2` 는 롬에 들어 있어서 막을 수 없습니다. `HGR2` 는 BASIC 프로그램이 들어 있는 메모리(`$4000–$5FFF`)를 지웁니다. **`HGR`** 는 한글 화면을 지우고 아래 네 줄을 글자 화면으로 바꿉니다. `TEXT`, `GR` 도 화면 모드를 바꿉니다. 실수로 썼다면 `HAN` 을 쳐서 한글 화면을 다시 켜 보세요(프로그램은 `HGR2` 가 지운 뒤라면 돌아오지 않습니다).
- **`MAXFILES`** 를 쓰지 마세요. 드라이버가 쓰는 메모리 보호가 풀립니다.
- **`INPUT` 으로 한글을 받으면** 답 문자열은 Ctrl-K 로 시작하고, 한글 입력이 끝나지 않은 채 Enter 를 쳤다면 끝에 한글 모드를 끝내는 Ctrl-A 가 자동으로 붙습니다. 그래서 `PRINT` 해도 다음 글자가 한글 모드로 바뀌지 않습니다. 단, 그 문자 하나만큼 `LEN` 이 늘어납니다(예: `한글` 의 `LEN` 은 8). 프로그램에서 답을 저장해 둔 한글 문자열과 비교하려면 그 문자열에도 끝에 Ctrl-A 가 있어야 합니다.
- 애플 II+ 자판에는 소문자가 없습니다. 소문자와 `|` 는 `CHR$` 나 텍스트 파일로 찍습니다.


## 10. 만든 이

만든 이: **KAPPLE**

한글2(Hangeul2)를 12×12 글꼴, 고해상도 1쪽 화면, 빠른 그리기, 영문 6×10 글꼴로 고쳤습니다. 프로그램은 어셈블리어(cc65)로, 글꼴은 `font.json` 에서 글꼴 편집기로 만듭니다. 자세한 내용은 프로젝트의 `docs` 폴더에 있습니다.
