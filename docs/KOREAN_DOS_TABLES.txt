K-HANGEUL 1.8 - 한글 DOS 명령과 메시지 (영어 -> 한글)
======================================================================

글은 UTF-8입니다. 여기 한글은 화면에 나오는 모습입니다. 이름을 치는 법과 한계는
MANUAL.md / MANUAL_en.md의 8, 8a, 8b절을 보세요.

(1) DOS 3.3 명령: 영어 이름 -> 한글 이름
----------------------------------------------------------------------

+------------+--------------+--------------------------------------------------------------------------------------------------------+
| 영어 (DOS) | 한글         | 설명                                                                                                   |
+============+==============+========================================================================================================+
| INIT       | 포맷         | 디스크를 포맷하고 메모리의 프로그램을 거기에 저장합니다(두 카드 모두. 새 디스크는 원래 DOS 3.3입니다). |
| LOAD       | 불러오기     | 디스크에서 BASIC 프로그램을 불러옵니다.                                                                |
| SAVE       | 저장         | 메모리의 BASIC 프로그램을 디스크에 저장합니다.                                                         |
| RUN        | 실행         | BASIC 프로그램을 불러와 실행합니다(이름이 없으면 메모리의 프로그램을 실행).                            |
| CHAIN      | 연결         | BASIC 프로그램을 불러와 실행하되 변수를 그대로 둡니다.                                                 |
| DELETE     | 지우기       | 디스크에서 파일을 지웁니다.                                                                            |
| LOCK       | 잠금         | 파일을 잠가서 바꾸거나 지우지 못하게 합니다.                                                           |
| UNLOCK     | 풀기         | 잠근 파일을 풉니다.                                                                                    |
| CATALOG    | 목록         | 디스크의 파일 목록을 보입니다. 한 쪽이 끝나 멈췄을 때 Ctrl-C를 누르면 끝납니다.                        |
| CLOSE      | 닫기         | 열려 있는 텍스트 파일(또는 모두)을 닫습니다.                                                           |
| READ       | 읽기         | 열려 있는 텍스트 파일에서 읽습니다.                                                                    |
| EXEC       | 일괄         | 텍스트 파일의 줄을 손으로 친 것처럼 차례로 실행합니다.                                                 |
| WRITE      | 쓰기         | 열려 있는 텍스트 파일에 씁니다.                                                                        |
| POSITION   | 자리         | 텍스트 파일에서 읽거나 쓸 자리(레코드)로 옮깁니다.                                                     |
| OPEN       | 열기         | 텍스트 파일을 엽니다.                                                                                  |
| APPEND     | 이어쓰기     | 텍스트 파일을 열고 끝에 이어서 씁니다.                                                                 |
| RENAME     | 이름바꿈     | 파일 이름을 바꿉니다.                                                                                  |
| MON        | 감시         | 디스크 입출력(명령, 자료)을 화면에 보입니다.                                                           |
| NOMON      | 감시끝       | 디스크 입출력 보임을 끕니다.                                                                           |
| MAXFILES   | 최대파일     | 한꺼번에 열 수 있는 파일 수를 정합니다.                                                                |
| HAN        | 한글         | 한글 드라이버를 다시 시작합니다(K-HANGEUL만 있음).                                                     |
| BSAVE      | 이진저장     | 이진 파일(메모리 범위)을 저장합니다.                                                                   |
| BLOAD      | 이진불러오기 | 이진 파일을 메모리에 불러옵니다.                                                                       |
| BRUN       | 이진가동     | 이진 파일을 불러와 실행합니다.                                                                         |
| VERIFY     | 검사         | 파일을 오류 없이 읽을 수 있는지 검사합니다.                                                            |
+------------+--------------+--------------------------------------------------------------------------------------------------------+

이름이 없는 것: PR#, IN#, FP (영어로 쓰세요). 영어 이름도 그대로 됩니다.
치는 법: Ctrl-K를 누르고 이름을 친 다음 공백을 칩니다. 영어 파일 이름이나 옵션이 오면
먼저 Ctrl-A를 누릅니다. 예:  Ctrl-K 저장 [공백] Ctrl-A T1.  한글 파일 이름은 그대로 한글을 이어 칩니다.
프로그램 안에서는 CHR$(4) 문자열에 넣습니다:  PRINT CHR$(4);"Ctrl-K 저장 T1"
이름은 줄의 첫 낱말이어야 합니다. PR#0(드라이버 끔) 뒤에는 한글 이름이 안 됩니다: HAN을 치세요.
KBASIC을 올리면 실행과 읽기는 KBASIC 낱말이기도 합니다(결과는 같습니다).
포맷(INIT)은 16K 카드와 Saturn 카드(1.7부터) 모두 디스크를 포맷합니다. 새 디스크는 K-HANGEUL 없이 부팅하는 원래 DOS 3.3입니다.
128K가 아닌 Saturn 카드(드라이버가 뱅크 7이 아님)에서는 DOS 메시지도 영어이고 INIT은 HAN처럼 드라이버를 다시 시작합니다.


(2) 메시지: 영어 -> 한글
----------------------------------------------------------------------

| 6    | FILE NOT FOUND               | 파일없음    |

2b. 애플소프트 BASIC 오류 메시지. 화면에는  ?<문구> 오류  로, 프로그램 안에서는  ?<문구> 오류 줄 <줄번호>  로 나옵니다.

| OVERFLOW             | 넘침       |

| REDIM'D ARRAY        | 배열중복   |

+----------------------+------------+

2d. 그 밖의 애플소프트 메시지 (오류가 아닌 것)

+----------------+-------------+---------------------------------------------------------------+
| 영어           | 한글        | 언제                                                          |

| ?REENTER       | ?다시 입력  | INPUT이 쓸 수 없는 글을 받았을 때(예: 숫자 자리에 글자)       |
+----------------+-------------+---------------------------------------------------------------+


(3) 아직 한글이 아닌 것, 확인하지 못한 것 (1.8)
----------------------------------------------------------------------

- 모니터 ROM의 글(예: 카세트 오류의 ERR), 정수 BASIC의 오류, ProDOS의 메시지, 다른 프로그램이 스스로 찍는 글.
- DOS의 출력 고리가 없을 때(PR#0, CSW를 드라이버로 바로 돌리는 프로그램)의 애플소프트 메시지: 영어로 남습니다.
- 128K가 아닌 Saturn 카드(드라이버가 뱅크 7이 아님): DOS와 애플소프트 메시지가 영어입니다.
- 애플 IIe, IIc: BREAK와 ?EXTRA IGNORED는 확인하지 못했습니다(ROM 글은 II Plus와 같습니다).
- 모든 시험은 MAME에서 했고 진짜 기계에서는 하지 않았습니다.
